# Playground

在线体验 GB/T 7714 Parser 的解析、格式化和校验功能。

<Playground />

## 使用说明

### 解析模式

输入参考文献字符串，点击"解析"按钮，查看解析后的结构化数据。

支持的输入格式：
- 顺序编码制：`[1] 张三. 论文标题[J]. 期刊名，2025，1：1-10.`
- 著者-出版年制：`(张三, 2025)`

### 格式化模式

输入参考文献字符串，点击"格式化"按钮，查看格式化后的标准引用字符串。

### 校验模式

输入参考文献字符串，点击"校验"按钮，查看该引用是否符合 GB/T 7714 规范。

## 支持的文献类型

- `J` - 期刊
- `M` - 图书
- `D` - 学位论文
- `C` - 会议录
- `R` - 报告
- `S` - 标准
- `P` - 专利
- `EB` - 网站/网页
- `A` - 档案
- `N` - 报纸
- `CM` - 地图
- `DS` - 数据集
- `PP` - 预印本
- `G` - 汇编
- `CP` - 计算机程序
- `DB` - 数据库
- `Z` - 其他

## 示例

### 期刊文章

```
[1] 张三，李四. 人工智能在教育中的应用[J]. 现代教育技术，2025，35(2)：15-22.
```

### 图书

```
[2] 李四. 机器学习导论[M]. 北京: 清华大学出版社, 2024: 156.
```

### 学位论文

```
[3] 王琦. 融合星载GNSS-R数据的土壤湿度反演方法研究[D]. 武汉: 武汉大学, 2022: 87.
```

### 在线资源

```
[4] Myburg A A, Grattapaglia D, et al. The genome of Eucalyptus grandis[J/OL]. Nature, 2014, 510: 356-362.
```

### 标准

```
[5] GB/T 7714-2025 信息与文献 参考文献著录规则[S]. 北京: 中国标准出版社, 2025.
```
